# ED2 Vibecoding Project

This repository contains code that was generated by AI (Google Gemini).

The above code is for a web app that allows users to manage a cloud-based to-do list.

# Features

The web app features user authentication (login, register, logout).

Back end functionality is provided by Back4App.com via the Parse API.

A bare-bones example Node web server is included to host the web app.

# Implementation

The web app itself consists of only two files, login.html and dashboard.html

login.html handles authentication (login, registration).

dashboard.html handles all functionality of the to-do list.

All JavaScript and CSS is inlined into the above two .html files.

# Quick Start Guide

To start the web server, make sure you have Node.js installed, then open a terminal in the repo directory and run ```Node server.js```.
